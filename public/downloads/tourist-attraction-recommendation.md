# 云游迹 · 旅游景点个性化推荐系统

> 毕业设计参考案例说明。本文档用于选题与方案设计参考，不含项目源码。

## 选题概述

利用用户评分、收藏和浏览行为构建旅游景点个性化推荐，在数据稀疏时结合分类偏好与热门景点完成回退。

## 核心功能

- 景点浏览、搜索、分类筛选与详情展示
- 评分、收藏和浏览足迹管理
- 基于用户的协同过滤推荐
- 景点、用户与演示数据管理

## 技术方案

- 前端：React 19
- 后端：Django 4.2、Django REST Framework
- 数据库：SQLite（默认）、MySQL 8.0（可选）
- 推荐策略：UserCF + 分类偏好 + 热门景点

## 可重点展开的论文内容

1. 多种用户行为的偏好权重设计
2. 用户相似度与候选景点评分
3. 新用户与数据稀疏场景的冷启动
4. 推荐接口的缓存与性能优化
5. 演示数据、运行截图与验收材料组织

## 开发环境

- Node.js 22 LTS
- Python 3.10+
- SQLite 或 MySQL 8.0
