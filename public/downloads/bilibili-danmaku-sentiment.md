# B站弹幕情感分析系统

> 毕业设计参考案例说明。本文档用于选题与方案设计参考，不含项目源码。

## 选题概述

抓取指定 B 站视频的弹幕数据，通过本地模型或云端服务完成情感分析，并用图表展示情感分布、关键词与时间趋势。

## 核心功能

- 按视频地址抓取并保存弹幕
- SnowNLP 与百度 AI 双引擎分析
- 情感极性分布、关键词词云与时间趋势
- 历史记录、热门排行和多视频对比

## 技术方案

- 前端：React 19、ECharts
- 后端：Django 4.2、Django REST Framework
- 文本处理：SnowNLP、jieba
- 数据库：SQLite / MySQL 8.0

## 可重点展开的论文内容

1. 弹幕数据采集、清洗与去噪
2. 本地模型与云端服务的结果差异
3. 情感得分与弹幕密度的时间序列分析
4. 外部服务不可用时的降级策略
5. 不同视频之间的横向对比指标

## 开发环境

- Node.js 22 LTS
- Python 3.10+
- SQLite 或 MySQL 8.0
- Redis（可选）
