# 知选 · 个性化商城系统

> 毕业设计参考案例说明。本文档用于选题与方案设计参考，不含项目源码。

## 选题概述

基于用户协同过滤构建完整商城应用，让浏览、加购、购买与评分行为持续参与个性化推荐。

## 核心功能

- 商品分类、搜索、筛选与详情浏览
- 购物袋、库存校验与订单创建
- 订单取消与库存回滚
- 浏览、加购、购买和评分行为采集
- 个性化推荐、热门回退与后台管理

## 技术方案

- 前端：React 19
- 后端：Django 4.2、Django REST Framework
- 数据库：SQLite
- 推荐策略：UserCF、余弦相似度、显著性收缩、热门补足

## 可重点展开的论文内容

1. 显式评分与隐式行为的统一偏好建模
2. 用户相似度计算与邻居选择
3. 数据稀疏情况下的冷启动策略
4. 订单事务对库存与推荐信号的同步维护
5. 推荐效果的离线评测方案

## 开发环境

- Node.js 22 LTS
- Python 3.10+
- SQLite
- Bash 3.2+
