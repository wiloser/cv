# 知径 · 个性化学习路径规划系统

> 毕业设计参考案例说明。本文档用于选题与方案设计参考，不含项目源码。

## 选题概述

面向在线学习场景，将课程拆分为带前置依赖的知识点图谱，并依据学习者掌握度、前置就绪度、难度匹配与群体反馈动态生成学习路径。

## 核心功能

- 课程、知识点与前置依赖图谱管理
- 用户注册、JWT 登录与选课
- 学习进度记录与掌握度更新
- 个性化学习路径生成与动态重算
- 推荐评分依据展示

## 技术方案

- 前端：React 19、Zustand
- 后端：Django 4.2、Django REST Framework
- 数据库：SQLite（开发环境）
- 推荐策略：知识依赖约束 + 掌握度 + 难度匹配 + 群体反馈

## 可重点展开的论文内容

1. 知识点前置关系的数据建模
2. 混合推荐评分的设计与权重说明
3. 冷启动与无可推荐节点时的回退策略
4. 推荐结果可解释性设计
5. 推荐算法与核心接口测试

## 开发环境

- Node.js 22 LTS
- Python 3.10+
- SQLite
